# Getting help with Asclepius

Start with the [live demo](https://safetymp.github.io/Asclepius/) or the
[documentation map](docs/README.md). Asclepius explains fictional care workflows
for healthcare stakeholders and includes a local FHIR teaching implementation.
**NOT_FOR_CLINICAL_USE:** it does not provide medical advice or support real
patient data, clinical systems, or production deployments.

| Need | Where to go |
| --- | --- |
| Understand the two journeys and their limits | [README](README.md), [Selected technical evidence](https://safetymp.github.io/Asclepius/workspace/) |
| Ask a usage or setup question | [Question form](https://github.com/SafetyMP/Asclepius/issues/new?template=question.yml) |
| Report broken behavior, confusing context, or accessibility friction | [Bug report](https://github.com/SafetyMP/Asclepius/issues/new?template=bug_report.yml) |
| Suggest an improvement | [Feature request](https://github.com/SafetyMP/Asclepius/issues/new?template=feature_request.yml) |
| Report a security vulnerability privately | [Security policy](SECURITY.md) |
| Report abusive conduct | [Code of Conduct](CODE_OF_CONDUCT.md#enforcement) |
| Contribute code, content, or design | [Contributor guide](CONTRIBUTING.md) |

Search [existing issues](https://github.com/SafetyMP/Asclepius/issues) first.
For demo feedback, include the journey and stage, what you expected, and the
browser/device used. For local setup, include the commit and relevant command
output. Use only synthetic examples; remove credentials and private information
from screenshots and logs. General questions and feedback are public.

Support is community-based; there is no clinical or production support service.
